# Feedback 360 DIENN 2026

Página web del Feedback 360 del equipo DIENN. Se publica con GitHub Pages desde `index.html` y guarda los datos en Firebase (Firestore).

- Notas públicas: todos las ven.
- Feedback privado: va cifrado en el navegador; solo lo puede leer quien lo recibe.
- `firestore.rules`: reglas de seguridad que se pegan en Firebase → Firestore → Reglas.
